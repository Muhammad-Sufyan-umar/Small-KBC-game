# 🎯 Kon Banega Crorepati – Python Quiz Game

A simple **"Kon Banega Crorepati" (KBC)** inspired quiz game built using Python.
The player answers a series of questions and wins increasing amounts of virtual money for every correct answer.

## 📌 Features

* 👤 Takes the player's name
* ❓ Asks multiple quiz questions
* 💰 Increases prize money after each correct answer
* ✅ Checks answers automatically
* ❌ Ends the game when an incorrect answer is given
* 🏆 Provides a final bumper prize for completing all questions
* 🔤 Uses `.lower()` to make answers case-insensitive

## 🛠️ Technologies Used

* Python 3
* `input()`
* `if-else` conditions
* Lists
* String methods
* Variables

## 🎮 How the Game Works

1. The player enters their name.
2. The game displays the welcome message.
3. The player is asked a series of questions.
4. Each correct answer increases the prize amount.
5. If the player gives a wrong answer, the game stops.
6. If all questions are answered correctly, the player wins the bumper prize.

## 💰 Prize Levels

| Level   |           Prize |
| ------- | --------------: |
| Level 1 |     Rs. 100,000 |
| Level 2 |     Rs. 200,000 |
| Level 3 |     Rs. 300,000 |
| Level 4 |     Rs. 700,000 |

## ❓ Questions Included

The game currently contains questions about:

* The first Mughal emperor of India
* The winner of the 2009 T20 World Cup
* Number of planets in the Solar System
* The planet known as the Red Planet

## ▶️ How to Run

Make sure Python is installed on your computer.

Run the following command in the terminal:

```bash
python main.py
```

Then enter your name and start answering the questions.
